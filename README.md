# AquaAssist 🐠

**Безплатно уеб приложение за проследяване на аквариум** — параметри на водата, обитатели, съвместимост, диагностика на здравето и поддръжка. Без регистрация, без инсталация — всички данни остават на твоето устройство.

🔗 **Live:** [aquaassist.app](https://aquaassist.app)

*Also known as: Aqua Assist, AquaAssistant, Aqua Asistent, Аква Асистент, АкваАсистент, Аква Ассист*

---

## Какво прави

AquaAssist е Progressive Web App (PWA) за аквариумисти — проследява всичко необходимо за здравето на аквариума на едно място:

- **Параметри на водата** — температура, pH, амоняк, нитрити, нитрати, GH, KH с история и графики
- **Обитатели** — риби, безгръбначни и растения с проверка на съвместимост помежду им
- **Диагностика на здравето** — автоматична оценка на състоянието на аквариума според текущите параметри
- **Графици и напомняния** — поддръжка, смяна на вода, дозиране на препарати с push известия
- **Наръчник (енциклопедия)** — справочна информация за видове риби, безгръбначни и растения
- **Калкулатор за обем** — изчисление на литри по размери на аквариума
- **Множество аквариуми** — управление на няколко резервоара от един акаунт
- **Облачна синхронизация** — незадължителна, през Firebase, между устройства
- **Двуезичен интерфейс** — български и английски, с автоматично разпознаване
- **Офлайн достъп** — работи без интернет връзка след първо зареждане

## Технологии

- **Чист HTML/CSS/JavaScript** — без build стъпка, без framework
- **Tailwind CSS** (чрез CDN) за стиловете
- **localStorage + IndexedDB** за локално съхранение на данни и снимки
- **Firebase Firestore** (незадължително) за облачна синхронизация между устройства
- **Service Worker** за офлайн работа и PWA инсталация (network-first за HTML, cache-first за останалите ресурси)
- **Google Analytics (GA4)** и **Cloudflare Web Analytics** за статистика на посещенията
- Хоства се статично през **GitHub Pages**

## Разработка

Приложението е **едностраничен файл** (`index.html`) без build процес — промените се правят директно в кода и се качват ръчно в GitHub (Settings → Pages), без `git push`.

При всяка съществена промяна:
1. Вдига се `APP_VERSION` в кода (и се добавя запис в `CHANGELOG`)
2. Вдига се `CACHE_NAME` в `service-worker.js`, за да се изчисти старият кеш при потребителите

## Поверителност

Всички данни на потребителя (аквариуми, параметри, снимки) се пазят локално на устройството му (`localStorage` + `IndexedDB`). Облачната синхронизация през Firebase е **изцяло незадължителна** и се включва ръчно от потребителя. Подробности в [privacy-policy.html](https://aquaassist.app/privacy-policy.html).
